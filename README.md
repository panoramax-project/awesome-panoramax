# awesome-panoramax

A collection of awesome things that use or support Panoramax !

*To add new cool tools you can [open an merge-request on our gitlab repo](https://gitlab.com/panoramax/docs/awesome-panoramax/-/merge_requests/new).

## Pre-upload tools

- **[GeoSillage](https://github.com/qhess34/geosillage)** pre-upload preparation tool to fix location, orientation and more

## Panoramax semantic tagging

- **[Panoramax Missing Tags](https://gitlab.com/mw014/panoramax-missing-tags)** quickly add missing transport=* tags to Panoramax sequences

## GIS tools

- **[Qgis Web Client (QWC)](https://github.com/qgis/qwc2)** is a modular next generation responsive web client for QGIS Server, built with ReactJS and OpenLayers.
- **[lizmap-web-client](https://github.com/3liz/lizmap-web-client)** Lizmap web application, by 3LIZ.

## OpenStreetMap integrations
- **[Podoma](https://github.com/osm-fr/podoma)** The OpenStreetMap statistics engine for thematic contributions!
- **[panoramax2osm](https://github.com/LaTeteDansLeGuidon/panoramax2osm)** OSM based POI map with nearby Panoramax pictures.

## OpenStreetMap contribution related
- **[https://gitlab.com/mw014/panoview](https://github.com/qhess34/geosillage)** road sign OSM integration helper


## Guessrz

- **[PanoramaxGuessr](https://github.com/kk327/panoramaxguessr)** is a FOSS alternative to GeoGuessr and other similar games.
- **[StreetSeekr](https://github.com/doen1el/street_seekr)** is an open-source alternative to GeoGuessr, based on Panoramax.
- **[RhenaGuessr](https://github.com/georhena-org/rhenaguesser)**

## Statistics / data-viz
- **[Streetscape Tracker](https://github.com/jonfroehlich/streetscape-tracker)** Analyze street-level imagery coverage and temporal patterns
